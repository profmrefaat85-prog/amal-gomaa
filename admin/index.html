موقع أ.د. آمال جمعة عبد الفتاح

أول تشغيل: أنشئ حساب المسؤول الرئيسي، واربط اللوحة بمستودع الموقع على GitHub بمفتاح وصول (Token).

إزاي أعمل مفتاح الوصول؟
  1. افتح صفحة إنشاء Fine-grained token من حساب GitHub صاحب المستودع.
  2. الاسم: لوحة تحكم موقع آمال جمعة، والصلاحية لمدة سنة (أو بدون انتهاء).
  3. Repository access: اختار Only select repositories ثم amal-gomaa.
  4. Permissions ← Repository permissions ← Contents: Read and write.
  5. اضغط Generate token وانسخه والصقه هنا. المفتاح يُحفظ مشفّرًا بكلمة مرورك ولا يُرسل لأي مكان غير GitHub.
