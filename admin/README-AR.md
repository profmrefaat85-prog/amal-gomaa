# لوحة تحكم الموقع

الرابط: https://amal-gomaa.duckdns.org/admin/

## أول تشغيل (مرة واحدة)
1. اعمل مفتاح وصول من GitHub (Fine-grained token) على المستودع `amal-gomaa` فقط، بصلاحية **Contents: Read and write**.
2. افتح رابط اللوحة، والصق المفتاح، واختار اسم مستخدم وكلمة مرور للمسؤول الرئيسي.

## الاستخدام
- كل تعديل يتحفظ في **مسودة** على نفس الجهاز، ومش بيظهر على الموقع غير بعد **مراجعة ونشر**.
- شاشة المراجعة بتعرض قائمة بالتعديلات (أخضر = جديد، برتقالي = معدّل، أحمر = محذوف) ومعاينة للموقع قبل وبعد.
- المحذوف بيروح **الأرشيف**، ويتسترجع بزرار واحد.
- **سجل النشر** فيه كل عمليات النشر، وتقدر تحمّل أي نسخة سابقة في المسودة.
- **المستخدمون** (للمسؤول الرئيسي فقط): إضافة محرر أو مسؤول بيوزر وباسورد، أو حذفه.

## ملفات
- `data.js` محتوى الموقع (بيتكتب من اللوحة).
- `admin/archive.json` الأرشيف.
- `admin/users.json` المستخدمين؛ المفتاح محفوظ مشفّر بكلمة مرور كل مستخدم (PBKDF2 + AES-GCM).
